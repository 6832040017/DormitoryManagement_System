# ระบบบริการจัดการหอพักออนไลน์ (Online Dormitory Management Service System)

เว็บไซต์จัดการหอพักครบวงจร พัฒนาด้วย **PHP + MySQL** ใช้งานได้ทั้งคอมพิวเตอร์และมือถือ (โทนสีพาสเทลฟ้า-ชมพู)

## ผู้ใช้งาน 3 กลุ่ม
| กลุ่ม | ความสามารถหลัก |
|---|---|
| **ผู้เช่า** | สมัครสมาชิกด้วยชื่อ+เบอร์โทร, ดูห้องว่างพร้อมรูป, จองห้อง (มัดจำ 1,000 บาท) ชำระผ่าน QR พร้อมเพย์ แนบสลิป, ดูบิล 4 รายการ (ค่าห้อง/ส่วนกลาง/ไวไฟ/น้ำ-ไฟ) พร้อมหน่วยมิเตอร์, แจ้งซ่อม, ดูประกาศ, ดู/พิมพ์สัญญาเช่าของตนเอง |
| **เจ้าของหอพัก** | จัดการห้อง (เพิ่ม/แก้ไข/ลบ/รูปภาพ), จัดการผู้เช่า, จดมิเตอร์และออกบิล, ตรวจสลิป (มีตัวเลขแจ้งเตือน), งานซ่อม, ประกาศ, สัญญาเช่า (ติดตามวันหมดสัญญา), แดชบอร์ดรายรับ, ตั้งค่า |
| **ผู้ดูแลระบบ** | จัดการบัญชีผู้ใช้ (ระงับ/ลบ/บันทึกรหัสผ่านใหม่), ดู Logs, จัดการข้อมูลแทนเจ้าของหอพัก |

หน้าแรกแสดงจำนวนห้องทั้งหมด/ห้องว่าง (แยกแอร์-พัดลม), ห้องว่างพร้อมรูป และห้องที่กำลังจะหมดสัญญาภายใน 60 วัน (ไม่แสดงข้อมูลผู้เช่า)

## ความปลอดภัยที่มีในระบบ
เข้ารหัสรหัสผ่าน (`password_hash`), PDO Prepared Statements, CSRF token, ตรวจชนิด/ขนาดไฟล์อัปโหลด, จำกัดการล็อกอินผิด, บังคับเปลี่ยนรหัสผ่านครั้งแรก, ตรวจสิทธิ์ตามบทบาท, ผู้เช่าเห็นเฉพาะข้อมูล/สัญญาของตนเอง, บันทึก Logs

## เทคโนโลยี
HTML, CSS, JavaScript, PHP 8.1+ (ทดสอบกับ 8.3), MySQL/MariaDB (ส่วนขยาย `pdo_mysql`, `fileinfo`), Chart.js และ qrcodejs (โหลดจาก CDN)

## ติดตั้งบนเครื่องตัวเอง (XAMPP)
1. คัดลอกโฟลเดอร์ไปไว้ที่ `C:\xampp\htdocs\dorm-system`
2. เปิด Apache และ MySQL ใน XAMPP แล้วสร้างฐานข้อมูลเปล่าชื่อ `dorm` (utf8mb4_general_ci) ใน phpMyAdmin
3. ตรวจค่าเชื่อมต่อใน `lib.php` (บรรทัดที่ 3: `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`)
4. เปิด `http://localhost/dorm-system/install.php` กรอกชื่อหอพัก บัญชีเจ้าของหอ และบัญชีผู้ดูแลระบบ (ติ๊ก "ข้อมูลตัวอย่าง" ถ้าต้องการสาธิต)
5. **ลบไฟล์ `install.php`** แล้วเข้าสู่ระบบที่ `http://localhost/dorm-system/`

## ติดตั้งบนโฮสติ้งจริง (สำหรับหอพักที่จะเปิดใช้งาน)
**ข้อกำหนดของเซิร์ฟเวอร์:** PHP 8.1 ขึ้นไป, MySQL/MariaDB, ส่วนขยาย `pdo_mysql` และ `fileinfo`, โฟลเดอร์ `uploads` เขียนไฟล์ได้, แนะนำให้เปิด HTTPS

1. สร้างฐานข้อมูล MySQL ในแผงควบคุมของโฮสต์ และจดชื่อเซิร์ฟเวอร์ ชื่อฐานข้อมูล ชื่อผู้ใช้ และรหัสผ่าน (โฮสต์ส่วนใหญ่ไม่ใช้ `localhost`)
2. อัปโหลดไฟล์ทั้งหมดไปที่โฟลเดอร์เว็บ (`public_html` หรือ `htdocs`) ให้ `index.php` และ `lib.php` อยู่ชั้นแรก
3. แก้บรรทัดที่ 3 ของ `lib.php` ให้ตรงกับฐานข้อมูลข้างต้น **(ห้ามนำไฟล์ที่ใส่รหัสผ่านจริงแล้วกลับไปเผยแพร่บน GitHub)**
4. เปิด `https://โดเมนของคุณ/install.php` ตั้งรหัสผ่านที่เดายากให้ทั้งสองบัญชี และ **ไม่ติ๊กข้อมูลตัวอย่าง**
5. **ลบไฟล์ `install.php`** ออกจากเซิร์ฟเวอร์ทันที
6. เข้าสู่ระบบเป็นเจ้าของหอ ไปเมนู **ตั้งค่า** กรอกชื่อผู้รับเงิน ธนาคาร เลขบัญชี พร้อมเพย์ ค่าน้ำ ค่าไฟ ค่าส่วนกลาง ค่าไวไฟ
7. เพิ่มห้องพักและรูปภาพที่เมนู **ห้องพัก** เพิ่มผู้เช่า และกำหนดสัญญาที่เมนู **สัญญาเช่า**

### เช็กลิสต์ก่อนเปิดให้ใช้งานจริง
- [ ] ใช้ HTTPS และลบ `install.php` แล้ว
- [ ] รหัสผ่านเจ้าของหอและผู้ดูแลระบบเดายาก (ระบบแนะนำให้ผู้เช่าเปลี่ยนรหัสผ่านครั้งแรกอยู่แล้ว)
- [ ] ใช้ผู้ใช้ฐานข้อมูลเฉพาะของเว็บนี้ ไม่ใช้บัญชี `root`
- [ ] สำรองฐานข้อมูลและโฟลเดอร์ `uploads` สม่ำเสมอ
- [ ] ตั้งเวลาเซิร์ฟเวอร์และเขตเวลาให้ถูกต้อง (ระบบใช้ Asia/Bangkok)
- [ ] ถ้ารูปในโฟลเดอร์ `uploads` ขึ้น Error 500 ให้ลบบรรทัด `php_flag engine off` ในไฟล์ `uploads/.htaccess` (บางโฮสต์ไม่รองรับคำสั่งนี้)
- [ ] แจ้งผู้เช่าเรื่องการเก็บข้อมูลส่วนบุคคล (ชื่อ เบอร์โทร สลิปโอนเงิน รูปแจ้งซ่อม) และจำกัดผู้ที่เข้าถึงบัญชีผู้ดูแลระบบ

## อัปเกรดจากเวอร์ชันก่อน
ทับไฟล์เดิมได้ ตารางและคอลัมน์ที่เพิ่มใหม่ถูกสร้างให้อัตโนมัติ (หรือนำเข้าไฟล์ใน `database/upgrade_v*.sql`) ตรวจ `DB_NAME` ใน `lib.php` หลังทับทุกครั้ง

## ค่าปรับชำระล่าช้า
เจ้าของหอตั้งค่าได้ที่เมนู **ตั้งค่า**: ค่าปรับต่อวัน (บาท) และเพดานสูงสุดต่อบิล (ใส่ 0 = ปิด/ไม่จำกัด) ระบบคิดอัตโนมัติสำหรับบิลที่เลยกำหนดและยังไม่ชำระ โดยรวมเข้ายอดรวมและ QR ของบิลนั้น ค่าปรับหยุดนับเมื่อผู้เช่าส่งสลิป (รอตรวจสอบ) และนับต่อหากสลิปถูกปฏิเสธ
ถ้าอัปเกรดจากเวอร์ชันก่อน ระบบเพิ่มคอลัมน์ให้อัตโนมัติ (หรือนำเข้า `database/upgrade_v5.sql`)

## โครงสร้างโฟลเดอร์
```
├── index.php, login.php, register.php, password.php   หน้าสาธารณะและบัญชี
├── tenant.php, book.php, lease.php                    ฝั่งผู้เช่า
├── owner.php, pending.php                             ฝั่งเจ้าของหอ
├── admin.php                                          ฝั่งผู้ดูแลระบบ
├── lib.php                                            ฟังก์ชันกลาง/การเชื่อมต่อฐานข้อมูล
├── install.php                                        ตัวติดตั้ง (ใช้ครั้งเดียว แล้วลบ)
├── database/                                          schema.sql และไฟล์อัปเกรด
├── assets/                                            CSS และ JavaScript
└── uploads/                                           รูปที่อัปโหลด (ไม่อยู่ใน Git)
```

## ข้อจำกัดที่ทราบ
- ระบบไม่ตรวจสลิปกับธนาคารโดยอัตโนมัติ เจ้าของหอพักเป็นผู้ตรวจสอบสลิป
- ไฟล์รูปสลิป/รูปแจ้งซ่อมใน `uploads/` ใช้ชื่อสุ่มที่เดายาก แต่เปิดได้ด้วยลิงก์ตรงโดยไม่ต้องล็อกอิน (ใครที่ได้ลิงก์จึงเปิดดูได้) หากต้องการความเข้มงวดขึ้น ควรพัฒนาให้ส่งไฟล์ผ่านสคริปต์ที่ตรวจสิทธิ์ก่อน
- ค่าส่วนกลาง ค่าไวไฟ ค่าน้ำ ค่าไฟ ตั้งได้ที่เมนูตั้งค่า
